# hamayastudio.com

Static public website for Hamaya Studio OS, served by GitHub Pages at https://hamayastudio.com.

- `index.html`: the whole page, with inline CSS and a small progressive-enhancement script.
- `assets/img/`: real Hamaya Studio OS product captures and the selected IMAGE Takes from "The Next Horizon".
- `CNAME`: the GitHub Pages custom domain.

The site has no backend, no secrets and no authentication. "Start creating" and "Log in" link to https://staging.hamayastudio.com.
